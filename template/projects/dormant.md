# dormant

Projects that don't currently warrant their own page. `/today` ignores
everything here.

| project | path | last real activity | note |
|---|---|---|---|

## Promote

When one gets meaningful activity: create `projects/<name>.md` (copy
`example-project.md`), give it `summary:`, `status: active`, `path:` and typed
`edges:`, remove its row here, `sare build pages`.

## Demote

An active page with no commits in 90+ days and nothing in **Next up** moves here:
one row, then delete the page (git keeps it).
